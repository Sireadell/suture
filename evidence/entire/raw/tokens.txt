$ entire tokens
Analyze token usage across sessions and checkpoints.

Commands:
  profile  Aggregate token usage across committed checkpoints

Examples:
  entire tokens profile
  entire tokens profile --json

Usage:
  entire tokens [flags]
  entire tokens [command]

  profile     Aggregate token usage and recommendations across checkpoint history

Flags:
  -h, --help   help for tokens

Global Flags:
